## 🚀 Despliegue y Ejecución

1. **Registrar comandos Slash con soporte de Servidores y DMs:**
   ```powershell
   npm run deploy
   ```

2. **Iniciar en Desarrollo:**
   ```powershell
   npm run dev
   ```

3. **Compilar e Iniciar en Producción:**
   ```powershell
   npm run build
   npm start
   ```
